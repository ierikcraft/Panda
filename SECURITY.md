# Política de Seguridad

## Versiones Soportadas

Actualmente, el navegador se encuentra en la versión 1.0. Esta versión seguirá recibiendo soporte y actualizaciones regulares de seguridad hasta el lanzamiento de la versión 2.0, previsto entre diciembre de 2026 y junio de 2027. 

La versión 2.0 marcará un nuevo hito y se llamará **Panda Alpha**, ya que a partir de esta actualización, todas las versiones mayores de Panda recibirán un nombre oficial.

| Versión | Soportada          |
| ------- | ------------------ |
| 2.0.x (Panda Alpha) | Próximamente       |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reportar una Vulnerabilidad

La seguridad es fundamental en el ecosistema de ErikHub. Si descubres una vulnerabilidad de seguridad en Panda, por favor no abras un *Issue* público de inmediato para evitar que otros puedan explotarla antes de que se solucione.

Para reportar un problema:
1. Utiliza la pestaña de **Security** > **Advisories** en este repositorio de GitHub para enviar un reporte privado, o ponte en contacto directo de forma privada.
2. Trataremos de confirmar la recepción de tu reporte en un plazo de 48 horas.
3. Te mantendremos informado sobre el estado de la vulnerabilidad (si es aceptada o rechazada) y los plazos previstos para lanzar un parche de seguridad que proteja a todos los usuarios.
